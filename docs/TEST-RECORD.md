## 中断和失败的如实记录

一次同时运行单元测试与打包桌面测试时，Windows 锁定了正在使用的受控测试 EXE，导致 71 项中的 2 项原生编译/后续调用测试失败。这是共享测试文件的并发冲突；之后按单元测试 → 构建 → 桌面测试串行执行，最终结果单独列出。

用户曾按 Escape 停止 Computer Use，已关闭当时的打包测试和受控窗口。该中断不算打包验证成功。本轮后续验证使用应用自身的自动化测试，不操作用户的其他应用。

监控加入后的初次开发模式测试中，受控窗口未获前台焦点，程序拒绝了回填；测试窗口调整启动顺序并等到目标可验证后，最终打包链路通过。重载测试脚本曾等待旧 renderer 的 JavaScript promise 而挂起，改为从新 renderer 和持久化记录验证完成。此处保留测试夹具问题，不把初次失败算作通过。

本机一个 Electron ZIP 缓存不完整，解压失败后使用完整的同版本已有缓存完成提取；未重新下载运行时，未下载模型或安装推理依赖。
