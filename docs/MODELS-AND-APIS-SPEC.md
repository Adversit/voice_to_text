## Provider/schema contract

- settings.asr.provider = custom|openai|groq|siliconflow|dashscope. Strict new saves require it; old schema-1 objects missing it migrate to custom preserving endpoint/model/stages. New defaults use custom. Cloud engine:'openai' remains existing cloud-route discriminator; provider selects actual wire protocol. Local settings retain provider for later.
- snapshot.speechProviders entries: {id,name,protocol,defaultEndpoint,endpoints:[{value,label}],defaultModel,models:[string],docsUrl,keyUrl,notes}. Named presets accept only listed official bases; custom accepts validated HTTPS. API model strings remain configurable. No unimplemented providers disguised as working presets.
- OpenAI/Groq/custom: multipart POST /audio/transcriptions, file/model/response_format=json, optional language. OpenAI gpt-transcribe instead uses languages[]; older models keep language. Response text.
- SiliconFlow: https://api.siliconflow.cn/v1, multipart file/model only, default FunAudioLLM/SenseVoiceSmall, response text. Omit unsupported language/response_format fields.
- DashScope: https://dashscope.aliyuncs.com/compatible-mode/v1 or https://dashscope-intl.aliyuncs.com/compatible-mode/v1; POST /chat/completions; Bearer key; JSON {model:'qwen3-asr-flash',messages:[{role:'user',content:[{type:'input_audio',input_audio:{data:'data:audio/wav;base64,...'}}]}],stream:false,asr_options:{enable_itn:false,language?:'zh'|'en'}}. Parse choices[0].message.content. Do not send multipart. Existing 120-second WAV fits documented base64 limits.
- Official protocol references: https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference ; https://docs.siliconflow.cn/docs/api/audio-transcriptions-post ; https://console.groq.com/docs/speech-to-text ; https://developers.openai.com/api/docs/guides/speech-to-text . Exact metadata and sources are documented alongside adapters before acceptance.

## Credential migration and UI contract

- Private secrets becomes {polish?:ciphertext,asrProviders?:{[provider]:{endpoint:string,encrypted:string}}}. Migrate legacy secrets.asr to current provider slot bound to exact stored normalized endpoint, remove old field atomically with provider migration. Preserve ciphertext; no decrypt/re-encrypt. Reject malformed/conflicting private fields without rewriting originals.
- Existing saveSettings({settings,keys?:{asr?,polish?}}) remains. Supplied ASR key updates only selected provider/address; empty clears that slot; omitted preserves all. getSecret('asr') resolves current provider AND exact endpoint, returning empty on mismatch. Changing custom host/region must not send an old key.
- Public settings.asr.hasKey reflects selected binding; asr.keyEndpoints:{[provider]:endpoint} supports draft status. Never expose keys/ciphertext. One saved binding per provider; switching regions may require another key. Public metadata is stripped by settings validation.
- Exact credential address matching uses the stored string after trimming whitespace and removing trailing slashes. Renderer must not canonicalize hostname casing, default ports or other URL spellings when comparing keys; transport URL normalization does not migrate existing encrypted bindings.
- UI provider picker fills endpoint/model suggestions in draft. Keep per-provider/address unsaved key drafts OR explicitly clear ASR key input on switch; never save old supplier key under new supplier. Preserve unrelated settings/polish/shortcut drafts. Optional empty key allows setup now. Say '待填写密钥' / '已配置，尚未实际验证'; no automatic health/balance calls. Official docs/key links must open only allowlisted external HTTPS pages through main, never arbitrary shell URLs.
- Requests enforce HTTPS/no redirects/bounded body+response/timeouts; errors do not echo response text, keys or audio into records/monitor. No background cloud calls or hidden retries. History/export schemas stay unchanged, no credentials/endpoints added.
