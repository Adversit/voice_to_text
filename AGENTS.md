# Repository instructions

Read and follow [agent.md](agent.md) for the user's durable goals and constraints, and [docs/SPEC.md](docs/SPEC.md) before cross-layer changes. Monitoring changes must also follow [docs/MONITORING-SPEC.md](docs/MONITORING-SPEC.md). Record all test results in project documentation before claiming tested behavior. No model downloads in this prototype phase. All model and inference cache paths must remain inside this project. Do not commit user data, credentials, audio, model weights, compiled executables or runtime caches. Original icon assets and screenshots from the isolated test fixture may be committed.
